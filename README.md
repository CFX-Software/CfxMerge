# CfxMerge

Merge duplicate FiveM resources & convert YTD textures.

## Downloads

Get the latest version from [Releases](https://github.com/CFX-Software/CfxMerge/releases):

| File | Description |
|------|-------------|
| `CfxMerge-amd64-installer.exe` | Windows Installer (Recommended) |
| `CfxMerge.exe` | Portable Version |

## Features

- **Duplicate Scanner** - Find duplicate `.ymap`, `.ytyp`, `.ybn`, `.ydr`, `.ymt` files
- **Cloud Merger** - Merge duplicates with one click
- **YTD Converter** - Extract textures from YTD files
- **Auto Backup** - Your files are always backed up

## Requirements

- Windows 10/11
- API Key from [cfx.software](https://cfx.software)

## Usage

1. Install & launch CfxMerge
2. Enter your API key
3. Select your resources folder
4. Scan → Select duplicates → Merge
